# Dungeon Keep Prototype

A real-time-with-pause dungeon management defense game built with Python and Pygame.

## Setup

```bash
pip install -r requirements.txt
```

## Run Locally

```bash
python main.py
```

## Build for Browser

```bash
pygbag .
```

Then serve `build/web/` with any static file server.
